# Style model of the experimental estimate

Generated by `scripts/train-style.ts` on 2026-11-02. Do not edit by hand.

**Training data:** 14,554 commits with a disclosed agent signature (signature lines removed) and 13,030 commits from before July 2022 (before coding agents) from the same 152 repositories. Commits by bot accounts are left out.

**Features (23):** log subj len, log prose len, has prose, log prose lines, log bullets, log backticks, md bold/heading, conventional, squash (#n), em dash/arrow, log sentences, long-line share, wrapped<=72, human trailers, lowercase subj, log max line, numbered list, explanatory phrases, two spaces after period, avg word len, first person, informal, identifiers in subject. Only the text of the commit message is used; no names, no dates, no diffs.

## How well it separates single commits

Area under the ROC curve with 5-fold cross-validation grouped by repository (a repository is never in training and test at once): **0.895**.

This is not good enough to judge a single commit, and howmuchai never does. Careful human writers (mailing-list projects such as PostgreSQL or QEMU) score like agents. The model is only used for a share per repository, against that repository's own history.

## Why there is a gate

2026 commits of projects with restrictive AI policies, estimated against their own pre-2022 commits. Their writing style changed over the years without any agent (longer review trailers, longer explanations), so an ungated estimate would accuse them. howmuchai therefore only estimates when a repository already discloses some AI use (at least 5 signed commits) or has agent setup files, and labels the result as experimental.

# Ground truth

`ground-truth.json` holds 163 commits and pull requests from 131 of the most-starred repositories, sampled on 2026-11-02 from the crawler's raw data with `scripts/eval-sample.ts` (fixed seed) and labelled by hand:

| Stratum | How it was drawn |
|---|---|
| `match <agent>\|<kind>` | Up to 4 items per signal kind that the classifier matched, each from a different repo |
| `near-miss` | 45 items that mention an agent or AI (claude, codex, copilot, cursor, gemini, llm, …) but did not match |
| `random` | 20 random items without a match |

Labels:

- `signature`: carries a standard agent signature (trailer, bot account, footer, marker, session link). `agent` says which.
- `prose`: discloses AI help only in free text ("I used Claude Code to write this"). Outside the scope of howmuchai; must not be counted.
- `hint`: only a default agent branch name such as `codex/…`. Plausible but not verifiable; must not be counted.
- `none`: no AI agent signature.

`npm run eval` checks the classifier against these labels and writes [`REPORT.md`](REPORT.md). The test suite fails on any false positive, missed signature or wrong agent.

Reviewing the sample found and fixed real gaps before launch: `Assisted-by:` trailers (Linux kernel and LLVM convention), the Devin co-author trailer and footer, `Copilot-Session:` trailers, the Copilot coding agent marker, the Cursor agent marker and footer, the Capy thread link, Claude Code session links and the italic `_Generated by [Claude Code](…)_` footer. The evaluator also caught two of my own labelling mistakes.

**Limits.** 163 items are a sample, not a proof. Labels were set by one person. Signals without an example in the sample are reported as "unvalidated". To add an item, append it to `ground-truth.json` with a public URL and a rationale; wrong results reported as issues are the best source.
